# Courriels officiels SDCD — 3 modèles
1. `courriel-officiel.html` — notification de suivi de dossier (bouton d'action, mise en avant, cartes d'aide).
2. `courriel-convocation.html` — convocation à un rendez-vous : récapitulatif date/heure/lieu, boutons calendrier/déplacer, encadré « pièces à apporter ».
3. `courriel-lettre-info.html` — lettre d'information : à la une, brèves à filets, agenda avec bouton.

Inspiré de dsfr-mail (structure en tables, mode sombre par prefers-color-scheme, blocs modulaires) mais entièrement à l'identité SDCD : filet tricolore, marque d'État aux armoiries, bleu #0095C9, blocs titre / mise en avant / cartes / pied RGPD (désabonnement, données personnelles).
Pour un envoi réel : héberger les armoiries sur une URL publique et remplacer le chemin relatif, tester Outlook/Gmail/Apple Mail.
