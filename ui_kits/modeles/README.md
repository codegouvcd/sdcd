# UI kit — Modèles de pages
Quatre pages complètes et fonctionnelles composées avec les composants du SDCD :
1. **Article d'actualité** — Article (chapo, partage, sommaire, hero), Quote, Gallery en corps, aside « À lire aussi » + TagCloud.
2. **Suivi de dossier** — recherche par n° avec validation de format, Tracking, FAQ en Accordion.
3. **Prendre rendez-vous** — Select démarche/lieu liés au composant Rdv, Calendar des ouvertures, alerte pièces.
4. **Médiathèque** — Carousel héro, Tabs Photos/Vidéos/Audio, Gallery + visionneuse, MediaPlayer, Pagination.
5. **Fiche démarche** — gabarit service-public : étapes numérotées, pièces en accordéon, coût/délais, textes de référence, aside « Où s'adresser » + rappel SMS fonctionnel.
6. **Tutoriel de connexion** — assistant en 3 étapes avec vraie validation (courriel, mot de passe, code SMS de démo 123456).
7. **Données** — indicateurs + BarChart / DonutChart / LineChart (inspirés de dsfr-chart) avec bascule graphique/tableau.
8. **Réclamation** — formulaire complet : objet, dossier lié, gravité, description validée, pièces, déclaration sur l'honneur, référence REC-.
9. **Demande de service** — assistant Wizard en 3 étapes réservé aux entités publiques.
Navigation par l'en-tête officiel ; tout est interactif (état React), images en zones de dépôt.
